# ADR-004: Scheduling

Status: Proposed (approve or change before Task 30)
Date: 2026-11-12

## Context
Two jobs run in the background: a nightly link check of about 260 products (two buttons each at most) and
click retention. The alternative weighed is Action Scheduler.

## Decision
WP-Cron: a daily event `affibloom_daily` at 03:00 starts the link check and click retention; the check runs in
chained single events `affibloom_link_check_batch`, guarded by the `affibloom_link_check_lock` transient.

## Why
The workload is a few hundred HTTP requests a night, which WP-Cron handles in small batches. Action Scheduler
would add a library and its tables for no benefit at this size.

## Consequences
Batches must stay short enough for a single request. On sites where WP-Cron depends on traffic, the check
may start later than 03:00, which is acceptable for a daily check.
