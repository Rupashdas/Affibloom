# ADR-001: Product storage

Status: Proposed (approve or change before Task 11)
Date: 2026-11-12

## Context
263 products today (Task 4 inventory: 233 Amazon, 21 other merchants, plus 9 Lasso records with no link).
Each product is read when a box renders and listed in the admin, ten to a page. The alternative weighed
(roadmap 1.4) is a custom table.

## Decision
A private custom post type `affibloom_product` (not public, no front-end URL, no core admin UI)
with fields in post meta prefixed `_affibloom_`.

## Why
Native caching (object cache, meta cache priming), export and revisions are available,
and the small number of rows needs no custom table.

## Consequences
Search by name uses WP_Query `s`. Lookups by URL use a `_affibloom_url_key` meta index.
