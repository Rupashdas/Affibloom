# ADR-007: Admin UI build

Status: Proposed (approve or change before Task 8)
Date: 2026-11-12

## Context
The admin screens follow Lasso's layout, labels and workflows (Dashboard, product page, Settings). Lasso builds
them as PHP-rendered pages with jQuery and Bootstrap. The alternative weighed is a React app on
`@wordpress/components`, themed to match Lasso.

## Decision
PHP-rendered screens, a small CSS kit using Lasso's colours, and plain JavaScript (the `wp.apiFetch` global, no
build step) for modals, quick edit, toasts and saving without a reload.

## Why
It is how Lasso builds the screens being matched, so the layout carries over directly. It keeps the admin free
of a build step, and only the block editor needs `@wordpress/scripts`.

## Consequences
Interactive pieces are small, separate scripts. Accessibility (focus, labels, keyboard use) is handled by hand
in the templates and checked in Task 37.
