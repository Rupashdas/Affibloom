# ADR-006: Box styling

Status: Proposed (approve or change before Task 18)
Date: 2026-11-12

## Context
Every box on the site uses Lasso's Lab theme in its single-product layout. The baselines from Task 5
(`tests/fixtures/baselines/variants/`) record how each kind of box looks. The alternative weighed is porting
Lasso's Lab CSS.

## Decision
A new stylesheet with `affibloom-` class names, tuned to match the Lasso baselines. No Lasso CSS is copied.

## Why
Separate class names let both plugins run on the same page during migration without their styles colliding.
A stylesheet written for one layout is far smaller than Lasso's, which covers every theme and display type.

## Consequences
Visual tests compare each box with its baseline within the agreed tolerance (`maxDiffPixelRatio` 0.01).
Small rendering differences are expected and are reviewed, not chased pixel by pixel.
