Status: Proposed (gate 1; approved with Task 6). Date: 2026-11-12.

## User stories

- As an editor, I give a product an optional second button, such as "Buy Now Women's Shoe".

## Acceptance criteria

- **AC1** It shows with its own text and link.
- **AC2** It is absent without a URL, or when it links to the page itself.
